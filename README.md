# KIRODA

Malaysia-first car financial decision app.

**Working tagline:** Kira sebelum pandu.

## V1
- Android-first (Flutter)
- BM default, English optional
- Offline-first, no login
- Legacy flat-rate hire purchase
- Reducing-balance fixed/EIR
- Variable-rate scenario support
- 5/7/9 year comparison
- Reverse budget calculator
- Rate Translator
- Scenario Lab A/B/C
- Share results as text/image

## Principles
Calculation logic is separated from UI. No sensitive documents or IC data. No production AI dependency. Rules/data are versioned and calculations are testable.
